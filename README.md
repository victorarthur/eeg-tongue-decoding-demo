# Tongue movement decoded from EEG, video examples

Video examples for the article "Noninvasive decoding of tongue movement from scalp EEG during speech using ultrasound tongue imaging".

The page is served at https://victorarthur.github.io/eeg-tongue-decoding-demo/

Each clip is the recorded ultrasound of the tongue during one test trial, with the tracked tongue contour (solid line) and the contour decoded from the EEG (dashed line), and with the speech of the trial as its sound.

The recordings belong to the dataset ds007920 on OpenNeuro (under review, doi:10.18112/openneuro.ds007920.v1.0.0).
